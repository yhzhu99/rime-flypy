# iPhone：小鹤音形（iRime / 超越输入法）

适用于使用 Space 文件结构的 **iRime 5** 和 **超越输入法（BiM）**。两者是独立 App，配置应导入实际使用的 App。这是本仓库的小鹤**音形**（`flypy`），不是内置的「小鹤双拼」。打包直接读取仓库的码表、词库和 Lua 扩展；不导出设备的学习词库、桌面改键或其他本机配置。

机器标识不依赖显示名：主方案与主词库为 `flypy`，反查方案与词库为 `flypydz`，仅 iPhone 主题使用 `flypy-ios`，和 BiM 自带的 `double_pinyin_flypy` 不冲突。

## 安装

在仓库目录运行 `uv run platforms/ios/package.py`，或用 `python platforms/ios/package.py`。默认输出到 `.local/bim/`，可用 `--output` 指定目录。

| 压缩包 | 在 iRime / BiM 中导入 | 文件服务器中的位置（先解压） |
| --- | --- | --- |
| `flypy-ios.zip` | 主题 → 导入 | `themes/flypy-ios/` |
| `flypy.zip` | 方案 → 导入 | `schemas/flypy/` |

1. 先导入主题，再导入方案。用 App 的文件服务器时，请将解压出的文件夹上传到表中对应的父目录；不要把 ZIP 放在服务器根目录，也不要覆盖内置方案、迁移目录或公共主题。
2. 回到 iPhone 上正在使用的 App，在「方案」或键盘的「键盘选择」中选 **小鹤音形**，执行「部署 / 重新部署 Rime」。方案已绑定 **小鹤音形 · iPhone**；若 App 保留了手动主题选择，在「主题」中切换到该主题。
3. 若尚未启用系统键盘，在 iOS 的「设置 → 通用 → 键盘 → 键盘 → 添加新键盘」添加对应 App 的键盘。打开备忘录，用地球键切到对应键盘测试。安装后可关闭文件服务器。

小鹤音形组的 `schema_list` 只显示 `flypy`；`flypydz` 仅供反查，不单独显示。无需删除其他方案组或词库。如需回退，在 App 切回原来的方案和主题即可；若只想排查主题，可保留小鹤音形方案，暂时切到标准中文 26 键主题。

## 屏幕键位与验收

- 中英文共用 QWERTY。`Q` 到 `P` 上滑输入 `1` 到 `0`，下滑输入符号；底栏中英键或空格上滑切换。`123` 点按打开数字页，上滑打开符号页。
- 两页底栏位置一致：`123`、中英、空格、标点、次选/句号、回车。左侧不重复放逗号，标点统一放在空格右侧：中文点按 `，`、上滑 `。`、下滑 `,`；英文点按 `,`，右邻键点按 `.`、上滑 `;`。
- 英文页的 `N` / `M` 上滑输出 `,` / `.`，`V` / `B` 输出 `?` / `!`；中文页的 `N` / `M` 上滑仍是 `，` / `。`。英文标点直接提交半角字符，不依赖 Rime 当前的标点映射。
- 中文底栏 `；` 无候选时用于快符（例如 `;w` → `？`），候选出现时可选第二项。上滑 `；` 发送反引号，可用缺码反查（例如 `` `irx `` 找「你」）；长按可清码。
- 不管回车键当前显示「发送」「搜索」还是「确认」，**上滑回车键换行**，与点按执行当前动作区分。键帽上方标出数字、标点、切换、反查或换行等上滑动作。
- `nihc` 加空格应输出「你好」；输入 `xhyx` 后接 `n`，前一组四码应先上屏为「小鹤音形」。`orq` 可检查日期候选。
- 主题继承 BiM 自带的数字页、符号页、候选栏和系统明暗配色。紧凑键距及首排手势参考 [Beyond-theme](https://github.com/zghnby0825/Beyond-theme)；没有使用该项目的主题文件或外部词库。

仓库的 librime 1.17.0 测试直接解包编译 `flypy.zip`，验证快符、四码顶字、反查、Lua 和中英文切换。触屏手势、配色和键盘启用仍需在 iPhone 上验收。
